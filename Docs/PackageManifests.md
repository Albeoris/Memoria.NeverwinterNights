# Shared package manifests

Each runtime package owns one `resources/<package>_memoria.json` source, emitted as a `<package>_memoria.txt` NWN resource. Schema 1 includes build-generated `version` and `dependencies` fields together with the source `schema`, `id`, and optional subsystem sections. Every `NwnRequiredPackage` supplies a dependency `ModId` and X.Y.Z `MinimumVersion`; an installed version is compatible when it has the same major and is greater than or equal to that minimum.

The shared [memoria_loader.nss](../Mods/Memoria/source/memoria_loader.nss) enumerates TXT resources from the `OVERRIDE:` key table once per loaded runtime and retains resrefs ending in `_memoria`. It rejects malformed or duplicate identities and recursively disables packages with missing, incompatible, or disabled dependencies. Both [memoria_boot.nss](../Mods/Memoria/source/memoria_boot.nss) and [memoria_config.nss](../Mods/Configuration/source/memoria_config.nss) consume that filtered list, so a disabled mod receives neither heartbeat dispatches nor configuration actions.
